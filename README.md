## 设计口径

每批两张章节卡、两章候选正文；每章正文2500–4000 Unicode非空白码点（含标点），由Python脚本复算；全书20–180万字、180万为本项目上限。作者08按15章闭区间审计；节点章未通过08不定稿。作者会话为人工切换，不存在自动调度、自动广播或平台级门禁。
