- 故障排查表：`用户使用指导/故障排查表.md`

## 技能包要点

GLM项目中一部长篇小说使用10个独立作者会话。正文每轮两章、每章2500–4000字；中篇20–90万字，长篇90–180万字，180万字为硬上限。项目状态通过文件区交接。作者07逐批做剧情/连续性及AI味双轨审计，作者08每15章做长周期审计，作者09通过门禁后定稿，作者10维护质量账本、趋势、卷末债务和全书健康报告。
