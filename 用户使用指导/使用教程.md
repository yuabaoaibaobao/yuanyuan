# 使用教程｜GLM 多会话长篇小说技能包

> 本文是ZIP外的快速导航，不是第二份运行规范。所有具体门禁、路径、模板字段、工具命令及故障恢复步骤，以所用版本ZIP中的`README.md`和`部署与运行手册.md`为准。发布者未用真实GLM账号做端到端测试。

## 1. 先确认运行环境

下载并解压技能包。ZIP根目录必须按既定布局：先是`01_自定义指令.md`、`02_长期记忆.md`，随后按序为作者01–10目录；不要添加外层目录，也不要把三份本教程类指南塞进ZIP。先读包内README与部署手册，后者是唯一部署步骤权威。Python脚本只用于其明确列出的静态校验，不证明平台能力或创作质量。

## 2. 部署前做一次小规模冒烟测试

在目标账号新建空白测试项目，按包内部署手册测试上传、另一会话读取、保存后回读、目录保留/拍平映射，以及01/02是否可见。记录实际入口、模型显示名、时间、结果与证据。任何关键步骤无法复现时暂停长篇项目，采用人工导出/导入交接或判断该平台不适用；发布者没有替你执行这些测试。

## 3. 按作者职责推进

作者01立项和确认用户选择；作者02处理研究资料；作者03维护经用户确认的设定真值；作者04规划双章章节卡；作者05写候选正文；作者06做限定范围润色；作者07进行有证据的剧情/风格风险审阅；作者08执行15章周期审计；作者09逐章核验并放行；作者10登记统计与周期报告。它们是人工切换的职责，不会自动互相调用或广播文件。

每个双章批次仍是两张卡和两章正文；每章目标码点数、生成中续写、审计门禁、唯一写入者及窗口边界均按包内现行文档执行。模型回复的“继续”不代表用户批准待决事项。每次切换前，先让用户保存权威项目状态和交接文件，再按已保存的下一动作启动下一个作者；不要依赖未落盘聊天内容。

## 4. 维护边界

三份ZIP外指南只提供导览、测试记录表和故障索引；更新时不复制包内规范。若此处与所用ZIP中的README、部署手册、会话指令或Schema不一致，暂停并以包版本为准，向维护者报告差异。旧版本项目不要直接套用新版模板；先备份并按部署手册迁移。
