## D. 流程试运行（空项目或测试副本）
- [ ] 作者01可以落盘口径确认单、风格指纹、检索需求。
- [ ] 作者02返回带链接/来源类型/结论限制/复用指引的资料。
- [ ] 作者03两阶段门禁能阻止未确认设定被锁定。
- [ ] 作者04能输出两张有编号、人物知识边界、伏笔状态、钩子和风险的卡。
- [ ] 作者05生成两章并分别报告字数、事实增量和卡片偏差。
- [ ] 作者06输出修订稿与改动证据卡。
- [ ] 作者07能把一个问题从AI味/剧情审计定位到段落并生成问题ID。
- [ ] 返修后作者07能复审并关闭/重开问题。
- [ ] 作者08在第15章节点报告跨章问题并门控作者09。
- [ ] 作者09只在门禁通过时写定稿索引并更新事实台账。
- [ ] 作者10账本能按问题ID统计通过、阻断、复发、返修与关闭。
- [ ] 每会话末尾均有下一步简易流程表；无阻断时“继续”可自动读文件推进。
