# 作者10｜质量账本与全书健康报告 独立技能包

## 本会话是谁
逐章登记检索、写作、去味润色、AI味审计、连续性问题和定稿结果；每15章报趋势、每卷总结债务、完结出全书健康报告，并用证据反哺04/05/06。

## 在全流程中的位置
作者10：按主项目状态索引触发。上下文隔离、文件区共享；只认有版本的项目文件。完成后用会话流程表明确下一站，不让用户手动复述。

## 快速开始
1. 打开并粘贴本文件夹的`会话指令.md`到GLM对应作者会话。
2. 确保项目文件区已上传本文件夹规范与上游文件。
3. 按`输入输出契约.md`逐项校验读取清单及文件版本。
4. 用户说“继续”后执行；若门禁或依赖缺失，停下并列清单。
5. 产出模板规定的文件、自检结果和按`输入输出契约.md`定义的交接字段填写交接包。

## 触发点与统计口径

逐章账本只纳入作者09已放行的最终版本；章节字数以工具对纯正文文件的结果为准，记录文件版本，返修旧稿不重复计入。每15章窗口由索引中的起止章（1–15、16–30…）触发一次趋势报告；第15章/30章等节点经作者08通过后再纳入已放行统计。卷末报告由作者03已确认的《总纲与分卷大纲.md》卷边界触发：该卷最后一章09放行后生成，未定义卷边界时暂停并请求作者03/用户补齐。完本报告在最后一章放行并完成人物/伏笔/问题债务清算后生成。

每轮只读状态索引、待记账的09放行单、相应07/08问题ID及当前窗口数据；不回读作者02–09全部历史产物。旧章节事实以真值台账和滚动摘要为索引，遇争议回查原文。趋势须列分子分母、窗口、缺失数据和样本限制；无基线时标“首次观测”，不写质量已提高。

## 输入与输出
- 主要读取：根级01/02；项目状态索引；本次待记账的09放行单/正文文件版本和工具统计；对应04卡片、05事实增量、06修改摘要、07问题状态；08报告（周期触发时）；确认卷界和未结债务摘要。按问题/台账ID回查原文件，不全量读取02–09历史产物。
- 必须产出：逐章账本记录；每15章趋势报告；由已确认卷边界触发的卷末债务报告；完本健康报告。模板均在本夹`模板/`；项目工作文件由用户复制模板后维护。
- 具体 schema 见`输入输出契约.md`和`模板/`。

## 门禁
不补编数据；分母、窗口、排除项写明；趋势仅产生规则候选，不自动改风格指纹/设定/体量/审计阈值；完结报告不能代替未通过的审计。

## 与其他作者的连接
把带证据的候选预防规则送04章节卡模板、05写作自检、06润色规则；07/08验证效果；下周期做对照，没改善/误伤即回滚。规则每项有ID、版本、生效章节、责任人、证据、结果。

## 缺文件降级
若01/02、状态索引或本会话必需输入缺失/冲突，停止当前产出，在索引标为“阻断”，列明缺失逻辑路径、预期提供者和恢复动作；不新建空白真值、不代替作者03补设定。仅本夹说明文件意外损坏时，可从本包同路径恢复并核对版本。完成文件补齐后由用户更新索引并明确恢复下一动作。

## 本夹文件结构
- `README.md`：本夹说明与独立使用流程。
- `会话指令.md`：可直接粘贴的会话级指令。
- `输入输出契约.md`：文件读取、产出、交接字段。
- `规范/执行规范.md`：目的/规则/判定/正反例/兜底五层规范。
- `模板/`：本会话交付表和交接包。
- `示例/正例.md`、`示例/反例.md`：可对照案例。
- `自检清单.md`：开工、收工和门禁三张清单。
- `变更记录.md`：本夹规范版本记录。
