# 作者04｜双章章节卡规划师 独立技能包

## 本会话是谁
每轮生成接下来两章的两张可执行章节卡；必须读取设定、伏笔/时间线/人物状态、最近两章和质量进化报告，让章节卡随审计证据逐步增强。

## 在全流程中的位置
作者04：按主项目状态索引触发。上下文隔离、文件区共享；只认有版本的项目文件。完成后用会话流程表明确下一站，不让用户手动复述。

## 快速开始
1. 打开并粘贴本文件夹的`会话指令.md`到GLM对应作者会话。
2. 确保项目文件区已上传本文件夹规范与上游文件。
3. 按`输入输出契约.md`逐项校验读取清单及文件版本。
4. 用户说“继续”后执行；若门禁或依赖缺失，停下并列清单。
5. 产出模板规定的文件、自检结果和按`输入输出契约.md`定义的交接字段填写交接包。

## 输入与输出
- 主要读取：根级01/02；作者01口径/风格指纹；作者03锁定总纲/当前卷纲；索引所列且与本批卡片相关的台账条目（不回读全量历史）；最近两章/上一章摘要与回查路径；上批卡片执行差异；最近相关07/08报告与10趋势；质量进化索引中已批准且适用本批的规则；作者02相关回传。
- 必须产出：两张章节卡（每卡一章，计划字数2500-4000字）；卡片执行约束/质量预防项；检索请求；版本化交接包。
- 具体 schema 见`输入输出契约.md`和`模板/`。

## 门禁
缺前两章或重要台账/版本冲突不得出卡；设定未锁不得把猜测写成事实；卡片与总纲冲突回03；任何新硬规则不得从一次偏好建议产生。

## 与其他作者的连接
输入03真值、07审计问题、08趋势、10账本；输出给05；章节卡偏差由07报告、09定稿回填实际执行；模板进化经10统计验证并带版本。

## 缺文件降级
若01/02、状态索引或本会话必需输入缺失/冲突，停止当前产出，在索引标为“阻断”，列明缺失逻辑路径、预期提供者和恢复动作；不新建空白真值、不代替作者03补设定。仅本夹说明文件意外损坏时，可从本包同路径恢复并核对版本。完成文件补齐后由用户更新索引并明确恢复下一动作。

## 本夹文件结构
- `README.md`：本夹说明与独立使用流程。
- `会话指令.md`：可直接粘贴的会话级指令。
- `输入输出契约.md`：文件读取、产出、交接字段。
- `规范/执行规范.md`：目的/规则/判定/正反例/兜底五层规范。
- `模板/`：本会话交付表和交接包。
- `示例/正例.md`、`示例/反例.md`：可对照案例。
- `自检清单.md`：开工、收工和门禁三张清单。
- `变更记录.md`：本夹规范版本记录。
