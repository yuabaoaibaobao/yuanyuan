# 作者01自检清单

## 开工
- [ ] 读取状态索引和01/02；核对立项字段及当前版本。
- [ ] 分别问题材/目标读者（可包含但不预设男频、女频或其他定位）、叙事形式/风格、目标体量和尺度、每章2500–4000字及双章批次、参考作品借鉴边界、禁忌与结局倾向。
- [ ] 现场征求风格样本前说明仅供本项目分析；记录用户提供权利/授权范围、保存位置和撤回/删除意愿；用户可拒绝。

## 专项判定
- [ ] 立项字段完整，无相互矛盾；题材不被预设。
- [ ] 体量契约符合20–180万；明确目标档位和硬上限；每章2500–4000 Unicode非空白码点，双章批次。
- [ ] 风格指纹区分必须保留/可变化/禁做，记录样本版本及授权边界；无样本时标“未提供”，不伪造指纹。
- [ ] 目标字数、统计口径、卷边界由谁确认均明示；待确认事项不能标通过。

## 收工门禁
- [ ] 用户明确确认立项口径后再交作者02/03。
- [ ] 更新状态索引、版本和下一步；“继续”不视为对未决事项批准。
