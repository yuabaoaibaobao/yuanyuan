# 作者01｜立项确认总控 独立技能包

## 本会话是谁
把用户的小说构想变成已确认、可检索、可写作的项目基线；只做立项、笔样采集、确认单和检索需求，不写大纲/人物/世界观。

## 在全流程中的位置
作者01：按主项目状态索引触发。上下文隔离；仅当本账号冒烟测试确认跨会话读写后，才按项目文件区路径读取；否则使用用户提供的拍平映射/文件副本，读不到即阻断。文件区行为未经验证前不作共享假设。完成后用会话流程表明确下一站，不让用户手动复述。

## 快速开始
1. 打开并粘贴本文件夹的`会话指令.md`到GLM对应作者会话。
2. 确保项目文件区已上传本文件夹规范与上游文件。
3. 按`输入输出契约.md`逐项校验读取清单及文件版本。
4. 用户说“继续”后执行；若门禁或依赖缺失，停下并列清单。
5. 产出模板规定的文件、自检结果和按`输入输出契约.md`定义的交接字段填写交接包。

## 输入与输出
- 主要读取：根级01/02；本夹README、会话指令、输入输出契约、规范、模板；若续作则项目状态索引与当前立项版本。
- 必须产出：写书口径确认单.md；风格指纹表.md；体量与节奏契约.md；检索需求文件.md；项目状态索引.md初版；交接包。
- 具体 schema 见`输入输出契约.md`和`模板/`。

## 门禁
用户确认单门禁未通过不得检索、设定或正文创作。用户未答不可当作默认同意。男频只在本会话询问，不写进01。重大需求变化重开变更确认。

## 与其他作者的连接
交作者02检索；检索回传后由作者01甄别采纳/否决/冲突，再将确认口径交作者03。后续作者04-10只读风格指纹和确认版本。

## 缺文件降级
若01/02、状态索引或本会话必需输入缺失/冲突，停止当前产出，在索引标为“阻断”，列明缺失逻辑路径、预期提供者和恢复动作；不新建空白真值、不代替作者03补设定。仅本夹说明文件意外损坏时，可从本包同路径恢复并核对版本。完成文件补齐后由用户更新索引并明确恢复下一动作。

## 本夹文件结构
- `README.md`：本夹说明与独立使用流程。
- `会话指令.md`：可直接粘贴的会话级指令。
- `输入输出契约.md`：文件读取、产出、交接字段。
- `规范/执行规范.md`：目的/规则/判定/正反例/兜底五层规范。
- `模板/`：本会话交付表和交接包。
- `示例/正例.md`、`示例/反例.md`：可对照案例。
- `自检清单.md`：开工、收工和门禁三张清单。
- `变更记录.md`：本夹规范版本记录。
