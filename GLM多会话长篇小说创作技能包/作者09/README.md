# 作者09｜审计后定稿 独立技能包

## 本会话是谁
只在章节审计及节点连续性审计通过、阻断和待裁定清零后，将润色稿锁为正式章节，并提交经核验的事实增量。

## 在全流程中的位置
作者09：按主项目状态索引触发。上下文隔离、文件区共享；只认有版本的项目文件。完成后用会话流程表明确下一站，不让用户手动复述。

## 快速开始
1. 打开并粘贴本文件夹的`会话指令.md`到GLM对应作者会话。
2. 确保项目文件区已上传本文件夹规范与上游文件。
3. 按`输入输出契约.md`逐项校验读取清单及文件版本。
4. 用户说“继续”后执行；若门禁或依赖缺失，停下并列清单。
5. 产出模板规定的文件、自检结果和六字段交接包。

## 输入与输出
- 主要读取：根级01/02；作者06 V1；07双轨审计与问题关闭证据；触发时08报告；03真值账本；04章节卡；所有返修版本和交接包。
- 必须产出：逐章定稿文件；定稿索引；章节卡完成状态；作者03账本变更；质量账本事件；项目状态索引；流程表。
- 具体 schema 见`输入输出契约.md`和`模板/`。

## 门禁
有阻断、重大待修、待用户裁决、节点08未通过、版本冲突、未批准卡片偏差，任何一项存在都不得生成定稿名或更新正式状态。不得静默覆盖旧定稿。

## 与其他作者的连接
输入07/08结论；返修回对应会话；放行后更新04卡片状态、03账本和10质量事件；已定稿章节若修改，创建修订版本并重跑受影响审计。

## 缺文件降级
若根级01/02或共享文件未上传，先请求用户在项目文件区补齐；不得假设读过。若仅本夹README/规范缺失，使用本目录同名规范补传。上游文件不存在时：若允许初始化则建立带“待确认/推定”标记的空白结构交作者03/用户确认；否则停笔。不得虚构前文、人物状态、审计结论或字数。

## 本夹文件结构
- `README.md`：本夹说明与独立使用流程。
- `会话指令.md`：可直接粘贴的会话级指令。
- `输入输出契约.md`：文件读取、产出、交接字段。
- `规范/执行规范.md`：目的/规则/判定/正反例/兜底五层规范。
- `模板/`：本会话交付表和交接包。
- `示例/正例.md`、`示例/反例.md`：可对照案例。
- `自检清单.md`：开工、收工和门禁三张清单。
- `变更记录.md`：本夹规范版本记录。
