# 作者08｜每15章连续性审计 独立技能包

## 本会话是谁
每15章检查跨章剧情、人物弧光、伏笔、时间、战力/规则、信息释放与AI味复发趋势；提供可执行返修与预防建议。

## 在全流程中的位置
作者08：按主项目状态索引触发。上下文隔离、文件区共享；只认有版本的项目文件。完成后用会话流程表明确下一站，不让用户手动复述。

## 快速开始
1. 打开并粘贴本文件夹的`会话指令.md`到GLM对应作者会话。
2. 确保项目文件区已上传本文件夹规范与上游文件。
3. 按`输入输出契约.md`逐项校验读取清单及文件版本。
4. 用户说“继续”后执行；若门禁或依赖缺失，停下并列清单。
5. 产出模板规定的文件、自检结果和按`输入输出契约.md`定义的交接字段填写交接包。

## 输入与输出
- 主要读取：根级01/02；当前15章正文/章节卡与作者07报告；作者03与本窗口15章相关的真值台账条目+索引/摘要回查指针；前一周期报告；作者10本窗口质量账本行/趋势和未结债务摘要（不要求所有历史产物）；作者02需要补检资料。
- 必须产出：每15章连续性审计报告；AI味与风格趋势小结；问题/债务清单；返修任务表；章节卡/正文改进建议；流程表。
- 具体 schema 见`输入输出契约.md`和`模板/`。

## 门禁
触发点第15/30/45章等；窗口截止章如待定稿，按已通过07的候选版预审，09需等08通过；硬矛盾未关闭不得放行节点章。明确区分事实问题与偏好意见。

## 与其他作者的连接
问题回03/04/05/06对应责任方；07局部复核后08复审；09定稿；10记账并提出趋势性改进候选；04/05/06只采用版本化且已批准/试行规则。

## 缺文件降级
若01/02、状态索引或本会话必需输入缺失/冲突，停止当前产出，在索引标为“阻断”，列明缺失逻辑路径、预期提供者和恢复动作；不新建空白真值、不代替作者03补设定。仅本夹说明文件意外损坏时，可从本包同路径恢复并核对版本。完成文件补齐后由用户更新索引并明确恢复下一动作。

## 本夹文件结构
- `README.md`：本夹说明与独立使用流程。
- `会话指令.md`：可直接粘贴的会话级指令。
- `输入输出契约.md`：文件读取、产出、交接字段。
- `规范/执行规范.md`：目的/规则/判定/正反例/兜底五层规范。
- `模板/`：本会话交付表和交接包。
- `示例/正例.md`、`示例/反例.md`：可对照案例。
- `自检清单.md`：开工、收工和门禁三张清单。
- `变更记录.md`：本夹规范版本记录。
