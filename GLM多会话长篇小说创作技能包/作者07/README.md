# 作者07｜双章剧情与AI味审计 独立技能包

## 本会话是谁
对每批两章执行双轨独立审计：剧情/连续性审计与AI味/风格保全审计；出具带证据问题ID，按责任会话返修并复审。

## 在全流程中的位置
作者07：按主项目状态索引触发。上下文隔离、文件区共享；只认有版本的项目文件。完成后用会话流程表明确下一站，不让用户手动复述。

## 快速开始
1. 打开并粘贴本文件夹的`会话指令.md`到GLM对应作者会话。
2. 确保项目文件区已上传本文件夹规范与上游文件。
3. 按`输入输出契约.md`逐项校验读取清单及文件版本。
4. 用户说“继续”后执行；若门禁或依赖缺失，停下并列清单。
5. 产出模板规定的文件、自检结果和六字段交接包。

## 输入与输出
- 主要读取：根级01/02；作者03锁定真值；04两张卡；05 V0与事实增量；06 V1与改动记录；前两章正文；02考据回传；审计规则/进化索引。
- 必须产出：章节审计记录.md；AI味审计记录.md；事实增量核验表；总审计结论；问题ID列表；流程表。
- 具体 schema 见`输入输出契约.md`和`模板/`。

## 门禁
剧情轨和AI味轨分别判断；两轨都通过且无待确认才进入09。不得只凭检测器或主观“像AI”判阻断；必须引用位置、风格指纹/规则和文本证据。审计者不得私自改稿。

## 与其他作者的连接
语言/AI味问题回06；卡片源头问题回04；正文执行问题回05；真值问题回03；所有返修回07复审；08按15章聚合；09确认零未结阻断；10按问题ID统计。

## 缺文件降级
若根级01/02或共享文件未上传，先请求用户在项目文件区补齐；不得假设读过。若仅本夹README/规范缺失，使用本目录同名规范补传。上游文件不存在时：若允许初始化则建立带“待确认/推定”标记的空白结构交作者03/用户确认；否则停笔。不得虚构前文、人物状态、审计结论或字数。

## 本夹文件结构
- `README.md`：本夹说明与独立使用流程。
- `会话指令.md`：可直接粘贴的会话级指令。
- `输入输出契约.md`：文件读取、产出、交接字段。
- `规范/执行规范.md`：目的/规则/判定/正反例/兜底五层规范。
- `模板/`：本会话交付表和交接包。
- `示例/正例.md`、`示例/反例.md`：可对照案例。
- `自检清单.md`：开工、收工和门禁三张清单。
- `变更记录.md`：本夹规范版本记录。
