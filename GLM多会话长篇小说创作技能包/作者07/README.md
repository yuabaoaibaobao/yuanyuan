# 作者07｜双章剧情与AI味审计 独立技能包

## 本会话是谁
对每批两章执行双轨分项审计：剧情/连续性审计与AI味/风格保全审计；出具带证据问题ID，按责任会话返修并复审。双轨是检查范围分开，不意味着独立模型或外部验证；审计来源需注明同模型/外部模型/人工。

## 在全流程中的位置
作者07：按主项目状态索引触发。上下文隔离；仅当本账号冒烟测试确认跨会话读写后，才按项目文件区路径读取；否则使用用户提供的拍平映射/文件副本，读不到即阻断。文件区行为未经验证前不作共享假设。完成后用会话流程表明确下一站，不让用户手动复述。

## 快速开始
1. 打开并粘贴本文件夹的`会话指令.md`到GLM对应作者会话。
2. 确保项目文件区已上传本文件夹规范与上游文件。
3. 按`输入输出契约.md`逐项校验读取清单及文件版本。
4. 用户说“继续”后执行；若门禁或依赖缺失，停下并列清单。
5. 产出模板规定的文件、自检结果和按`输入输出契约.md`定义的交接字段填写交接包。

## 输入与输出
- 主要读取：根级01/02；作者03锁定真值；04两张卡；05 V0与事实增量；06 V1与改动记录；前两章正文；02考据回传；审计规则/进化索引。
- 必须产出：章节审计记录.md；AI味审计记录.md；事实增量核验表；总审计结论；问题ID列表；流程表。
- 具体 schema 见`输入输出契约.md`和`模板/`。

## 门禁
剧情轨和AI味轨分别判断；作者09仅在阻断和待用户裁决均为0、必需审计证据完整时放行；一般主观风格建议不拦截。不得只凭检测器或主观“像AI”判阻断；必须引用位置、风格指纹/规则和文本证据。审计者不得私自改稿。

## 与其他作者的连接
语言/AI味问题回06；卡片源头问题回04；正文执行问题回05；真值问题回03；所有返修回07复审；08按15章聚合；09确认零未结阻断；10按问题ID统计。

## 缺文件降级
若01/02、状态索引或本会话必需输入缺失/冲突，停止当前产出，在索引标为“阻断”，列明缺失逻辑路径、预期提供者和恢复动作；不新建空白真值、不代替作者03补设定。仅本夹说明文件意外损坏时，可从本包同路径恢复并核对版本。完成文件补齐后由用户更新索引并明确恢复下一动作。
