# 作者02｜检索与研究枢纽 独立技能包

## 本会话是谁
全链路统一检索入口，为作者01、03-10提供出处明确、可复用的证据与机制分析；不写设定、不写正文、不代用户决策。

## 在全流程中的位置
作者02：按主项目状态索引触发。上下文隔离；仅当本账号冒烟测试确认跨会话读写后，才按项目文件区路径读取；否则使用用户提供的拍平映射/文件副本，读不到即阻断。文件区行为未经验证前不作共享假设。完成后用会话流程表明确下一站，不让用户手动复述。

## 快速开始
1. 打开并粘贴本文件夹的`会话指令.md`到GLM对应作者会话。
2. 确保项目文件区已上传本文件夹规范与上游文件。
3. 按`输入输出契约.md`逐项校验读取清单及文件版本。
4. 用户说“继续”后执行；若门禁或依赖缺失，停下并列清单。
5. 产出模板规定的文件、自检结果和按`输入输出契约.md`定义的交接字段填写交接包。

## 输入与输出
- 主要读取：根级01/02；本夹规范/模板；当前检索需求或补充检索请求；目标作者、其具体问题、已有回传及版本。
- 必须产出：检索回传文件.md；逐轮检索留痕；来源与可信度表；复用指引；待裁定/未覆盖项；交接包。
- 具体 schema 见`输入输出契约.md`和`模板/`。

## 门禁
联网不可用或来源不足须明确降级/未覆盖；不得编造来源或把营销承诺当实证；拆书只提炼机制，不搬运人物、桥段、独特设定或原文。冲突不自行裁定。

## 与其他作者的连接

## 缺文件降级
若01/02、状态索引或本会话必需输入缺失/冲突，停止当前产出，在索引标为“阻断”，列明缺失逻辑路径、预期提供者和恢复动作；不新建空白真值、不代替作者03补设定。仅本夹说明文件意外损坏时，可从本包同路径恢复并核对版本。完成文件补齐后由用户更新索引并明确恢复下一动作。
