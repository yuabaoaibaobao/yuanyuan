# 作者02｜检索与研究枢纽 独立技能包

## 本会话是谁
全链路统一检索入口，为作者01、03-10提供出处明确、可复用的证据与机制分析；不写设定、不写正文、不代用户决策。

## 在全流程中的位置
作者02：按主项目状态索引触发。上下文隔离、文件区共享；只认有版本的项目文件。完成后用会话流程表明确下一站，不让用户手动复述。

## 快速开始
1. 打开并粘贴本文件夹的`会话指令.md`到GLM对应作者会话。
2. 确保项目文件区已上传本文件夹规范与上游文件。
3. 按`输入输出契约.md`逐项校验读取清单及文件版本。
4. 用户说“继续”后执行；若门禁或依赖缺失，停下并列清单。
5. 产出模板规定的文件、自检结果和六字段交接包。

## 输入与输出
- 主要读取：根级01/02；本夹规范/模板；当前检索需求或补充检索请求；目标作者、其具体问题、已有回传及版本。
- 必须产出：检索回传文件.md；逐轮检索留痕；来源与可信度表；复用指引；待裁定/未覆盖项；交接包。
- 具体 schema 见`输入输出契约.md`和`模板/`。

## 门禁
联网不可用或来源不足须明确降级/未覆盖；不得编造来源或把营销承诺当实证；拆书只提炼机制，不搬运人物、桥段、独特设定或原文。冲突不自行裁定。

## 与其他作者的连接
作者01立项、03设定考据、04章节卡、05正文、06去味润色、07章节审计、08十五章审计、09定稿核验、10趋势/健康报告均可补检。补检按统一请求编号，回传带对应需求版本。

## 缺文件降级
若根级01/02或共享文件未上传，先请求用户在项目文件区补齐；不得假设读过。若仅本夹README/规范缺失，使用本目录同名规范补传。上游文件不存在时：若允许初始化则建立带“待确认/推定”标记的空白结构交作者03/用户确认；否则停笔。不得虚构前文、人物状态、审计结论或字数。

## 本夹文件结构
- `README.md`：本夹说明与独立使用流程。
- `会话指令.md`：可直接粘贴的会话级指令。
- `输入输出契约.md`：文件读取、产出、交接字段。
- `规范/执行规范.md`：目的/规则/判定/正反例/兜底五层规范。
- `模板/`：本会话交付表和交接包。
- `示例/正例.md`、`示例/反例.md`：可对照案例。
- `自检清单.md`：开工、收工和门禁三张清单。
- `变更记录.md`：本夹规范版本记录。
