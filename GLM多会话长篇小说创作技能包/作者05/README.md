# 作者05｜双章正文创作 独立技能包

## 本会话是谁
按作者04两张章节卡与立项风格指纹连续写两章；每章2500-4000字，接续前文，及时提交事实增量而不擅改锁定台账。

## 在全流程中的位置
作者05：按主项目状态索引触发。上下文隔离、文件区共享；只认有版本的项目文件。完成后用会话流程表明确下一站，不让用户手动复述。

## 快速开始
1. 打开并粘贴本文件夹的`会话指令.md`到GLM对应作者会话。
2. 确保项目文件区已上传本文件夹规范与上游文件。
3. 按`输入输出契约.md`逐项校验读取清单及文件版本。
4. 用户说“继续”后执行；若门禁或依赖缺失，停下并列清单。
5. 产出模板规定的文件、自检结果和按`输入输出契约.md`定义的交接字段填写交接包。

## 输入与输出
- 主要读取：根级01/02；作者01口径、风格指纹、体量契约；作者03锁定设定与连续性台账；作者04两张卡；上一章定稿、最近两章正文、滚动摘要、上批审计差异；作者06/07近期有效规则与作者08/10趋势；作者02本批检索回传。
- 必须产出：两章正文V0；每章字数与卡片对应表；事实/状态增量候选；卡片偏差报告；交接包与流程表。
- 具体 schema 见`输入输出契约.md`和`模板/`。

## 门禁
卡片缺失或未锁、上一章正文缺失、人物/规则台账冲突时停笔；超字数需说明而非灌水；不得擅自改大纲、世界规则、人物底线、风格指纹。

## 与其他作者的连接
从04拿卡；读取03真值；06处理文风；07审计剧情与AI味；返修项按ID闭环；09定稿后更新章节卡执行状态及03台账；10统计写作质量。

## 缺文件降级
若01/02、状态索引或本会话必需输入缺失/冲突，停止当前产出，在索引标为“阻断”，列明缺失逻辑路径、预期提供者和恢复动作；不新建空白真值、不代替作者03补设定。仅本夹说明文件意外损坏时，可从本包同路径恢复并核对版本。完成文件补齐后由用户更新索引并明确恢复下一动作。

## 本夹文件结构
- `README.md`：本夹说明与独立使用流程。
- `会话指令.md`：可直接粘贴的会话级指令。
- `输入输出契约.md`：文件读取、产出、交接字段。
- `规范/执行规范.md`：目的/规则/判定/正反例/兜底五层规范。
- `模板/`：本会话交付表和交接包。
- `示例/正例.md`、`示例/反例.md`：可对照案例。
- `自检清单.md`：开工、收工和门禁三张清单。
- `变更记录.md`：本夹规范版本记录。
