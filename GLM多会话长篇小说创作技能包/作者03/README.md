# 作者03｜设定总控与全书规划 独立技能包

## 本会话是谁
统一生成并维护总纲、卷纲、人物、世界观、规则、伏笔、时间线和连续性账本；经用户简版/详细版确认后成为唯一事实源。

## 在全流程中的位置
作者03：按主项目状态索引触发。上下文隔离；仅当本账号冒烟测试确认跨会话读写后，才按项目文件区路径读取；否则使用用户提供的拍平映射/文件副本，读不到即阻断。文件区行为未经验证前不作共享假设。完成后用会话流程表明确下一站，不让用户手动复述。

## 快速开始
1. 打开并粘贴本文件夹的`会话指令.md`到GLM对应作者会话。
2. 确保项目文件区已上传本文件夹规范与上游文件。
3. 按`输入输出契约.md`逐项校验读取清单及文件版本。
4. 用户说“继续”后执行；若门禁或依赖缺失，停下并列清单。
5. 产出模板规定的文件、自检结果和按`输入输出契约.md`定义的交接字段填写交接包。

## 输入与输出
- 主要读取：根级01/02；作者01确认单、风格/体量节奏契约；作者02检索回传；续作需读定稿正文索引、作者10报告、所有台账版本。
- 必须产出：简易版/详细版设定与总纲；状态锁；人物设定与弧光表；世界观规则表；伏笔清单；时间线；人物状态/知识边界表；战力与能力账本；信息释放节奏表；字数累计表；变更单；交接包。
- 具体 schema 见`输入输出契约.md`和`模板/`。

## 门禁
简版未获反馈不得扩写；详细版未确认不得锁定/动笔。变更须写旧值、新值、理由、影响章节/章节卡/台账/已写正文、回改方案；需用户确认后升版；在状态索引登记受影响会话，由项目所有者逐项交接文件版本并取得接收回执，不存在自动通知。

## 与其他作者的连接
04章节卡从本会话读取唯一事实源；05事实增量先作为候选；07/08提出冲突而不改真值；09通过后确认状态更新；10统计规则补丁、人物弧光与伏笔债务。

## 缺文件降级
若01/02、状态索引或本会话必需输入缺失/冲突，停止当前产出，在索引标为“阻断”，列明缺失逻辑路径、预期提供者和恢复动作；不新建空白真值、不代替作者03补设定。仅本夹说明文件意外损坏时，可从本包同路径恢复并核对版本。完成文件补齐后由用户更新索引并明确恢复下一动作。

## 本夹文件结构
- `README.md`：本夹说明与独立使用流程。
- `会话指令.md`：可直接粘贴的会话级指令。
- `输入输出契约.md`：文件读取、产出、交接字段。
- `规范/执行规范.md`：目的/规则/判定/正反例/兜底五层规范。
- `模板/`：本会话交付表和交接包。
- `示例/正例.md`、`示例/反例.md`：可对照案例。
- `自检清单.md`：开工、收工和门禁三张清单。
- `变更记录.md`：本夹规范版本记录。
